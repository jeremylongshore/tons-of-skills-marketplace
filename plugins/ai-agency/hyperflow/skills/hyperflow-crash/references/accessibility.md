# Accessibility review

For affected UI, inspect semantic names and roles, keyboard operation, visible focus, focus order, error association, reduced motion, and screen-reader announcements. Check narrow and zoomed layouts and long translated strings. Use an authorized browser or device when visual or interaction behavior matters; source inspection alone is not browser evidence.

Report the user task that fails, the input or navigation path, and the observed result. Do not claim WCAG conformance from a checklist or automated scan alone.
