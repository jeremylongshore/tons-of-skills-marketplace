# Performance review

Measure the affected user action under recorded device, browser, network, data, and build conditions. For web UI, inspect LCP, INP, CLS, and action timing. For services, inspect latency distributions, errors, database/query cost, load, and stability when the change warrants them.

Prefer traces or repeatable measurements over source-level guesses. State the baseline, changed result, and environment. Do not claim a performance budget passed when no measurement was run.
