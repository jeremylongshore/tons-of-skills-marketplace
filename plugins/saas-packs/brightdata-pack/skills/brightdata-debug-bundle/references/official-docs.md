# brightdata-debug-bundle — Official Contract

Checked 2026-09-13 against current Bright Data public documentation.

## Contract Applied

Support evidence is allowlist-built and private. Current provider error fields are useful; raw target content, secret-bearing proxy URLs, and credentials are never part of the default bundle.
