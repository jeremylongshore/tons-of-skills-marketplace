# brightdata-prod-checklist — Official Contract

Checked 2026-09-13 against current Bright Data public documentation.

## Contract Applied

Production readiness is broader than connectivity. The gate requires explicit target and data authority, current failure handling, bounded resource use, observability, and tested rollback.
