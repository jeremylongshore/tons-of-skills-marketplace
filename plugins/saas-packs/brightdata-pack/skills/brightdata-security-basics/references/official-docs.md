# brightdata-security-basics — Official Contract

Checked 2026-09-13 against current Bright Data public documentation.

## Contract Applied

The acceptable-use policy excludes nonpublic information behind login and abusive or fraudulent uses. Least-privilege account or zone access and application-enforced target and data controls are both required.
