## Contract notes

Never market AI review as a replacement for independent security assurance.

The live CodeRabbit documentation and generated configuration or API references are authoritative when they change after this review date. Git-provider documentation is authoritative for provider-owned branch, webhook, identity, and event behavior. Re-verify plan prices, limits, permissions, schema fields, and feature availability immediately before a live change.
