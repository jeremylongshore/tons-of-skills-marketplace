# Official Canva sources

Consulted: 2026-09-13

## Scope

These first-party sources establish application authorization using scopes, capabilities, and tenant policy.

## Sources

- [Capabilities](https://www.canva.dev/docs/connect/capabilities/)
- [Get user capabilities](https://www.canva.dev/docs/connect/api-reference/users/get-user-capabilities/)
- [OAuth scopes](https://www.canva.dev/docs/connect/appendix/scopes/)

## Boundary

Canva scopes and capabilities are inputs to application authorization; they are not a Canva-side custom RBAC API.
