# Official Canva sources

Consulted: 2026-09-13

## Scope

These first-party sources establish preview webhook verification, routing, and idempotency.

## Sources

- [Webhooks](https://www.canva.dev/docs/connect/webhooks/)
- [Webhook keys](https://www.canva.dev/docs/connect/api-reference/webhooks/keys/)
- [OAuth scopes](https://www.canva.dev/docs/connect/appendix/scopes/)

## Boundary

Webhooks are preview and outgoing-only; public integrations using preview features cannot pass review.
