# Incident communication template (do not send)

Reference only. The agent does not post to Slack, email, or status pages.

```
Subject: [SEV-?] <issue title> — <project>
Suspect release: <payload release or unknown>
Started: <firstSeen from payload only>
Users / events: <userCount> / <count>
Next check: <one line>
```

If a field is unknown, write unknown. Do not fill a timeline with plausible minutes. Do not attach the auth token.
