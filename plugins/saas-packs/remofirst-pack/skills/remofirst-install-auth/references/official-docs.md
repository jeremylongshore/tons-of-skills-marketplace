# RemoFirst secure access evidence

Reviewed: 2026-09-12

## Primary sources

- [Client account activation](https://knowledgebase.remofirst.com/hc/en-us/articles/34755661366164-How-to-activate-your-account-as-a-Client) — password, terms, company review, and billing-contact flow.
- [Client two-factor authentication](https://knowledgebase.remofirst.com/hc/en-us/articles/34910927256340-Securing-your-Remofirst-Account-with-2FA-Two-Factor-Authentication-for-Clients) — authenticator, recovery-code, login, and disable flows.
- [Manager access groups](https://knowledgebase.remofirst.com/hc/en-us/articles/34711781448340-Managing-access-rights-with-groups) — documented groups, permissions, and implicit Superuser default.
- [Client resource hub](https://knowledgebase.remofirst.com/hc/en-us/articles/42339401785620-RemoPack-Clients-Resource-Hub) — account, hiring, payroll, team, benefits, and offboarding lanes.
- [Support channels](https://knowledgebase.remofirst.com/hc/en-us/articles/40237072233236-How-do-I-contact-RemoFirst-for-support) — email, in-platform chat, tickets, and evidence guidance.
- [Workday connector guide](https://knowledgebase.remofirst.com/hc/en-us/articles/53164120410644-Workday-RemoFirst-Integration-Client-Guide) — customer-provisioned OAuth credentials for the named connector.
- [ADP connector guide](https://knowledgebase.remofirst.com/hc/en-us/articles/39824562179348-ADP-Workforce-Now-Connecting-to-RemoFirst) — short-lived account ID, connector activation, and SSO.

## Contract notes

The reviewed public sources document human client accounts and two named
connectors. They do not publish a general RemoFirst API-key, bearer-token, SDK,
endpoint, or rate-limit contract. Provider-issued private documentation remains
authoritative for any customer-specific interface.
