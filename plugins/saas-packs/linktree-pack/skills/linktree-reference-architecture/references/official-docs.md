## Evidence Rule

When public guidance, account behavior, and an approved partner contract differ, stop and have the Linktree account owner or partner-integration owner reconcile them. Never fill an undocumented interface with a generic SDK, host, endpoint, API key, OAuth flow, webhook signature, event name, quota, payload, or retry assumption.
