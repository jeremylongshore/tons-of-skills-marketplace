Checked 2026-09-12 against Anima's public SDK repository at commit

## Contract Applied

The backend SDK uses an Anima token; Figma generation also needs a valid Figma token. Figma OAuth integrations use the documented read scopes, while personal tokens must remain server-side and out of logs.
