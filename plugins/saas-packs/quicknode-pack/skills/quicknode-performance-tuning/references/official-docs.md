# Official QuickNode sources

Consulted: 2026-09-13

## Scope

These first-party sources establish endpoint percentile metrics, method/error segmentation, dashboard windows, and usage measurements.

## Sources

- [Endpoint metrics API](https://www.quicknode.com/docs/admin-api/endpoint-metrics/v0-endpoints-id-metrics)
- [QuickNode dashboard metrics](https://www.quicknode.com/guides/quicknode-products/how-to-use-the-quicknode-dashboard)

## Boundary

Measure one declared workload; do not generalize latency or batching behavior across chains and methods.
