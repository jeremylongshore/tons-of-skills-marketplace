# brightdata-reference-architecture — Official Contract

Checked 2026-09-13 against current Bright Data public documentation.

## Contract Applied

The architecture separates approval and control from bounded collection, quarantines untrusted results, validates before release, and constrains delivery to approved destinations with auditable evidence.
