# Stakeholder Update Evidence and Review Checklist

Use this checklist before sending an operational or executive update.

1. Use `Glob` to locate current status artifacts, `Grep` to find commitments and metric names, and
   `Read` to inspect the evidence behind each headline.
2. Lead with overall status, material change since the last update, and the decision or help needed.
3. Give every metric a definition, comparison point, direction, target, and reporting window.
4. Pair each risk with impact, owner, mitigation, and decision date. Separate confirmed facts from
   forecasts and assumptions.
5. Remove background that does not change a decision. Verify names, dates, links, and owners before
   delivery.

Use only already-authorized systems and existing authentication. Never request or include API keys,
tokens, passwords, or other credentials in the update. If live data access is unavailable, label
the last verified timestamp instead of implying freshness.
