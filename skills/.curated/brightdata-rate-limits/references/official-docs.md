# brightdata-rate-limits — Official Contract

Checked 2026-09-13 against current Bright Data public documentation.

## Contract Applied

Proxy capacity is adaptive rather than a single published global number. Dataset concurrency can be account or dataset specific; all limits remain explicit local budgets until provider and canary evidence justify change.
