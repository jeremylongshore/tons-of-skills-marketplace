# Cost experiment planning: evidence and failure boundaries

## Review details

Missing usage or rate data makes a monetary conclusion unknown. Never substitute a public approximate price or an assumed percentage discount.

Do not patch the containers array with a JSON merge patch to change one resource field: it may replace other container fields. Review the complete manifest or a manager-supported targeted change.

## Receipt fields

Record context/namespace identifiers only in the approved private incident system, UTC collection time, selected resource names, command exit status, missing permissions, and any review decision. Separate observed state, inferred cause and proposed change. A denied or incomplete check remains unknown, never a clean bill of health.
