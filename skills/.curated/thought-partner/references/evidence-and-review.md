# Thought Partnership Evidence and Review Checklist

Use this checklist when ambiguity can be reduced with available project context.

1. Use `Glob` to locate relevant plans, `Grep` to find prior decisions and assumptions, and `Read`
   to inspect the evidence before asking the user to repeat known context.
2. Reflect the outcome being sought, then separate hard constraints, soft constraints, assumptions,
   preferences, and missing evidence.
3. Generate materially different options and compare them against explicit decision criteria.
4. Test the favored option with a pre-mortem, strongest counterargument, and evidence that would
   reverse the choice.
5. Synthesize agreements, unresolved tensions, owner, and the smallest useful next action.

Do not prolong exploration after the decision criteria point clearly to an action. Ask a question
only when its answer can change the recommendation.
