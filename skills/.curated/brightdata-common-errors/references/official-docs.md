# brightdata-common-errors — Official Contract

Checked 2026-09-13 against current Bright Data public documentation.

## Contract Applied

Current provider diagnostics are `Proxy-Status` and `x-brd-err-code`, `x-brd-error`, and `x-brd-err-msg`. Legacy `x-luminati-*` headers are excluded from the current response contract.
