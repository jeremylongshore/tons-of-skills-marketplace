# Official embed references

Checked on 2026-09-10 against current first-party documentation.

- [StackBlitz JavaScript SDK](https://developer.stackblitz.com/platform/api/javascript-sdk) — methods for existing projects, public GitHub paths, and generated inline projects.
- [SDK options reference](https://developer.stackblitz.com/platform/api/javascript-sdk-options) — current open/embed options and deprecated `forceEmbedLayout`.
- [Controlling embeds](https://developer.stackblitz.com/platform/api/javascript-sdk-vm) — returned VM integration surface.
- [WebContainers browser support](https://developer.stackblitz.com/platform/webcontainers/browser-support) — browser constraints that affect WebContainer-backed embeds.
- [WebContainers troubleshooting](https://webcontainers.io/guides/troubleshooting) — cross-origin-isolated embed requirements.

The SDK documentation states that generated new projects remain in browser memory unless the user forks them into a StackBlitz account. Preserve that persistence boundary in product copy.
