# MCP large-result annotation opportunities

Source snapshot: `ce980701733ef5e6e798f17c1a3f21daf721387b`. Audit date: 2026-10-23. Parent: `claude-41c2.7`; implementation follow-up: `claude-41c2.10` (P3, open).

This pass inspected all 15 top-level roots under `plugins/mcp/`, their 18 package manifests (including nested packages), server registrations and relevant result builders. The [machine census](2026-10-23-platform-feature-census.json) binds all 272 tracked JavaScript, TypeScript, Python and JSON source/configuration paths in that subtree by SHA-256. Test/example files, generated distributions, bundled SDK internals and actual authored servers are different populations. No provider, remote MCP endpoint, local MCP server, native bootstrap or delegated MCP executable was invoked. No descriptor or payload was edited.

The [official Claude MCP reference](https://code.claude.com/docs/en/mcp) describes `_meta["anthropic/maxResultSizeChars"]` on each **tools/list descriptor**, with a default text persistence threshold of 50,000 characters and an annotation ceiling of 500,000. Large successful text can be persisted to disk; the annotation changes that threshold. It does not repair lost or truncated server data. Images and the separate unannotated output-token setting have different limits. The vendor annotation does not establish a portable guarantee in the [MCP tool protocol](https://modelcontextprotocol.io/specification/2025-11-25/server/tools).

No literal `anthropic/maxResultSizeChars` annotation was found in the inspected 272 files. Generic SDK support for `_meta` in the governed-brain bundle does not mean a tool advertises this specific annotation. No measured serialized character maxima exist from this read-only audit, so every proposed annotation value remains **unset pending fixture measurement**. Defaults and page-size limits below bound rows or transport bytes, not serialized result characters.

All roots have an explicit disposition. Candidate identification is an engineering judgment from the named result builders, not a measured claim that any particular call exceeds 50,000 characters. Follow-up work must bind ownership/provenance, capture deterministic small/large fixtures, preserve pagination/resource behavior and demonstrate the exact annotation in tools/list before claiming adoption.
