## Method and limits

All Git-tracked plugin Markdown beginning with a frontmatter delimiter was inspected with `parse_frontmatter` and `parse_allowed_tools` from the pinned repository validator. There are 3,011 parsed explicit `allowed-tools` fields; 230 artifacts in 8 roots contain an explicit unrestricted token (`Bash`, `Bash:*`, `Bash(*)`, `Bash(*:*)` or `*`). The earlier SKILL-only scan found 221 artifacts in 5 roots and is superseded by this wider scope. The full 230 paths, original field values, parsed tokens, existing denials and SHA-256 hashes are in the census. Missing fields are not classified as explicit allows-all. Agent `tools`/`disallowedTools` fields are a separate contract.

There were 59 frontmatter parse exceptions: 51 Geepers agent files and 8 other files/templates. They are retained as unknown parse outcomes, not safe passes. Only two contain the literal `allowed-tools`, both unexpanded skill-creator templates; neither is an executable skill permission declaration. No malformed external content was repaired. Source ancestry was checked with `resolvePluginProvenance`; five mirror roots cover 221 artifacts, while three no-marker roots cover 9 commands. The resolver's no-marker result is not a legal ownership finding.

Conservative review means testing the actual workflow before adding a deny, including nested `.env` paths and shell variants. `Edit(.env)` alone must not be advertised as protection for every environment file. Existing positive/negative fixtures and contributor permission are required before any payload change.

The [official skills reference](https://code.claude.com/docs/en/skills) describes skill-scoped tool permissions. Restrictions are active for the skill's current turn; they do not establish an application-wide security boundary. Broad permission alone does not prove malicious behavior or an exploitable path.

## Reproduce the snapshot

Run `python3 freshie/audits/verify-platform-feature-census.py --compare-worktree` from a checkout containing the frozen commit and matching canonical parser. The verifier re-enumerates the pinned Git universe, uses the repository parser, compares candidate/exception/configuration sets, searches every enumerated MCP source file for the literal annotation, and compares recorded SHA-256 values with Git blobs and working bytes. Without `--compare-worktree`, it verifies only frozen source, so a later working checkout does not redefine the snapshot. It does not run providers, hooks, MCP servers or performance benchmarks.

All population numbers are derived observations at the source commit. `.claude-plugin/marketplace.extended.json` remains the canonical live catalog; `scripts/publication-policy.cjs` owns eligibility and `scripts/corpus-resolver.mjs` owns graded/visible/curriculum membership. The census records their source hashes and catalog hash. Raw path populations are inventory observations, not publication or ownership decisions. Beads remains the live task authority; the stated issue statuses are audit-time observations.

The current [skill frontmatter reference](https://code.claude.com/docs/en/skills) explicitly documents `disallowed-tools` and the current [hook reference](https://code.claude.com/docs/en/hooks) documents space-wildcard Bash rules. These documented forms do not prove compatibility on an installed runtime; that remains a follow-up fixture requirement. Source ancestry here means the local directory chain to a source marker. It does not certify current upstream HEAD parity or legal ownership.
